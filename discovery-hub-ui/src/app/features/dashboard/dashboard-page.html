Demo path

  1. Search the archive, then add a result set to a case as evidence.
  2. On the case, attach custodians and move it Draft → Active.
  3. Place a legal hold and watch it propagate asynchronously.
  4. Try to delete a held message — the platform refuses and records the refusal.
  5. Request an export, then verify the manifest checksums.
  6. Read the whole story back in the audit trail.
