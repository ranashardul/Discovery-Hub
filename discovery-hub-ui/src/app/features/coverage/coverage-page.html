How these numbers are produced

One command runs every suite in the repository and rewrites the report this page reads: 

cd infrastructure
./coverage-report.sh                  # all suites, integration tests included
./coverage-report.sh --no-integration # skip Testcontainers, no Docker needed
./coverage-report.sh --skip-tests     # re-aggregate existing reports only
